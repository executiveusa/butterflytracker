# MORPHOS Y MONARCAS — PROJECT LOCK

**Code identity:** butterflytracker  
**Public brand/domain:** Morphos y Monarcas / morphosymonarcas.com  
**Mode:** Brownfield reconstruction

## Outcome
Create a Puerto Vallarta butterfly conservation platform that makes local species emotionally memorable and turns citizen observations into structured, exportable evidence for habitat monitoring, education, research, and public decision-making.

## Primary users
1. Residents / visitors who encounter a butterfly.
2. Local naturalists, educators and conservation groups.
3. Researchers / government teams that need quality-controlled occurrence evidence and monitoring gaps.

## Primary public action
**Record an observation.**

## Governing experience idea
**Scroll through an ecosystem, not through website sections.**
A specimen encounter unfolds into identity → evidence → ecology → conservation question → place → observation.

## Protected truths
- Every displayed taxon is real.
- Jalisco-level evidence must not be presented as Puerto Vallarta occurrence evidence.
- AI suggestion is never labeled as verified identification.
- 3D models are interpretive presentation, not taxonomic diagnostic plates.
- Public scientific maps only show records allowed by evidence/privacy rules.
- No fake government partnership, fake conservation impact, fake users, fake counts or fake observations.

## Release thresholds
Use Collins protocol: overall >= 8.5; usability, visual design, originality and accessibility >= 8.5; primary conversion >= 9; critical failures 0; unverified claims 0; mobile overflow 0; rollback documented.
